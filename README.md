# Web Jammer

Web Jammer is a web application designed for campus device management, student app restriction monitoring, and administrative control.

## 🚀 Features

- **Admin Module**: Device management, student & staff administration, app restriction controls, and settings.
- **Student Module**: Live restriction clock, app status grid, notifications, and device synchronization.
- **Staff Module**: Student overview and restriction tracking.
- **Authentication & Security**: Protected routes, role-based navigation, and error boundaries.

## 🛠️ Technology Stack

- **Frontend**: React, Vite, TailwindCSS / Custom Styling
- **Icons & Visuals**: Lucide React / Custom Components
- **Routing**: React Router DOM

## 💻 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
